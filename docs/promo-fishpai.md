# 我把公众号排版台搬进了 DSH 的侧边栏：鱼排 FishPai

写一篇公众号文章，最花时间的往往不是写，而是**在两个窗口之间来回搬**：让 AI 拟稿，粘进编辑器，手动加粗、分小标题、插图；突然发现某一段还得改，又回到 AI 那边，把上下文重新讲一遍。

麻烦的根源在于——**AI 看不见你的编辑器**。它不知道你刚把第二段删了、标题换成了疑问句、哪里还留着一句"这里补个数据"。于是每改一次，你都要先把改动向它描述一遍。

鱼排（FishPai）想解决的正是这一段。它是一个跑在 DeepSeek Harness 里的插件：排版台直接长在 AI 的侧边栏，你和它看的是同一份文档、同一套 Markdown。

> **一句话概括**
> 你在侧栏改稿，模型读懂你改了什么，成品仍然由你复制粘贴进公众号。

## 它是怎么工作的

正文就是一个**普通的 Markdown 文件**，躺在你的工作目录里，任何编辑器都能打开。鱼排只做三件事：把它渲染成公众号的样子、记下"这一段被谁改过"、把成品写进剪贴板。中间那条"谁改过"，是它和常见排版工具最大的区别。

## 它比普通排版工具多做了一件事

多数工具解决的是"Markdown 怎么变好看"，鱼排多解决了一件事：**让模型看懂你在稿件上做了什么**。

1. **块级 diff** ｜ 模型读到的不是全文，而是"第 4 段改了、第 7 段是新加的"
2. **批注** ｜ 光标停在哪一段，就能留一句只写给模型看的话
3. **占位** ｜ 正文里写 `<!-- 鱼排: 这里补个数据 -->`，模型会把它当成待办
4. **防覆盖** ｜ 每次写入都带版本号，版本不对就当场拒绝，并回带"自你上次写入以来的改动"
5. **微信兼容** ｜ 复制过去不再被结构校验报"行高过小"，引用块的框、表头底色也不会掉

## 顺手的地方

编辑器支持 Markdown 快捷键：选中文字 `Ctrl/⌘ + B` 加粗、`+ I` 斜体、`+ K` 链接、`+ Alt + 1/2/3` 标题、`+ Shift + 8/7` 列表，列表里回车自动接着写下一项。截图或图片文件直接 `Ctrl/⌘ + V` 粘进来，图会存到文档同级的 `assets/` 目录，正文里自动插入引用。

右边是实时预览，可以切到 375px 看手机上的样子；主题有 11 套，按"是否适合公众号"分组，不适合的那几套会直接说明原因，而不是让你粘过去才发现掉样式。

:::tip 装它只要一行命令
在 DeepSeek Harness 里执行 `dsh plugin --profile web add "github:OMSociety/dsh-fishpai#v0.1.0"`，重启后右侧栏就会多出「鱼排编辑器」。
:::
