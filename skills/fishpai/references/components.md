# 鱼排专业组件手册

专业管线（`target: 'xiumi'`）提供自由 HTML/SVG 画布、语义组件与 SMIL 交互组件。组件是快捷方式，不是创作上限；可以按用户素材自由构图、裁切、分层、配色和组织整页版式。

## 用法总览

组件有两种插入方式，按场景选：

1. **面板「⊕ 组件」抽屉**（推荐人操作）：点按钮选组件，自动在光标处插入对应的 `:::` 指令块。
2. **手写 `:::` 容器指令**（推荐 AI 操作）：直接在 Markdown 里写，Agent 用 `fishpai_write` 插入。

预设组件产出内联样式 HTML 与 SVG，不依赖 `id` 联动或 CSS 动画。`raw` 是受控自由画布，保留安全 HTML/SVG，但拒绝脚本、事件处理器和危险 URL。规格、组件必填内容与 raw 安全边界由插件自动校验；`fishpai_lint` 是按需使用的结构提示工具。

## 静态版式组件

### 章节头 `chapter_header`

```
:::chapter_header
#1
章节标题
章节副标题
:::
```

三行依次是编号、主标题、副标题；编号可写 `#1`、`ONE` 等，副标题可留空，也可换行书写以控制窄屏断行。适合活动、系列专题和多章节长文。

### 信息卡 `info_card`

```
:::info_card
@卡片标题
正文支持 **Markdown**、列表与链接。
:::
```

首行以 `@` 开头时作为卡头，省略该行则只显示卡体。适合时间、地点、规则等一组完整信息；正文主体不要全部装进卡片。

### 重点行 `highlight`

```
:::highlight
11 月 15 日开始
:::
```

用小面积底色突出短句、日期或关键结论，支持行内 Markdown。

### 制作名单 `credits`

```
:::credits
文案｜姓名
设计｜姓名
排版｜姓名
:::
```

每行一个角色，使用全角 `｜` 或半角 `|` 分隔。

### 卡片 `card`

```
:::card
这里是卡片内容，支持 **加粗** 等行内格式。
:::
```

### 双栏 `two_columns`

`---` 单独一行分左右两栏：

```
:::two_columns
左栏内容
---
右栏内容
:::
```

### 渐变横幅 `gradient_banner`

```
:::gradient_banner
一句话标语
:::
```

### 编号步骤 `number_steps`

```
:::number_steps
第一步：做什么
第二步：做什么
:::
```

每行一条，自动编号。也支持 `-` 或 `1.` 列表写法。

### 引用卡 `quote` 与波浪分隔 `wave_divider`

```
:::quote
引用内容
:::

:::wave_divider
:::
```

`wave_divider` 无正文，产出一条装饰分隔。

## 交互组件（SMIL，粘进公众号可点/可动）

> 机制：微信公众号正文禁用 CSS `@keyframes`/`transition`，但为交互排版保留了 **SVG SMIL** 窄缝——`<animate>`/`<animateTransform>`/`<set>` + `begin="click"` 可用。鱼排的交互组件全部是「外层 SVG 动画层 + 内层普通内容层」的混合分层，在保留 SMIL 的阅读环境中可点击；粘贴到目标编辑器后的保留程度以该编辑器处理为准。
>
> 组件使用纯 SMIL `begin="click"`，不依赖 `id` 联动或脚本。内容层使用普通内联 HTML，动画层使用纯 SVG；展开组件采用零高正文容器与 SVG 高度动画。组件交互通过自动回归检查，真实设备行为在最终候选上验收。

### 点击展开 `expand`

```
:::expand
点我展开（封面提示文字）
---
这里是展开后才显示的内容，支持 **加粗**、列表等。
:::
```

`---` 前是封面提示，后是展开内容。适合「答案/详情/剧透」折叠。

`expand` / `swap` 是单向展开组件。无 `id` 的纯 SMIL 在同一热区没有可靠的展开/收起状态切换，因此不把「再次点击收起」作为组件能力。

### 点击换图展开 `swap`

```
:::swap
封面图或封面文字
---
展开后的内容
:::
```

### 滑动切换图集 `swiper`

```
:::swiper
https://example.com/1.png
https://example.com/2.png
https://example.com/3.png
:::
```

每行一个图片 URL。注意：**外链图会被微信拦**，需先在公众号后台转存，或改用本地图（复制时自动内嵌）。

### 探照灯 `spotlight`

```
:::spotlight
被照亮的关键内容
:::
```

### 弹幕 `danmaku`

```
:::danmaku
第一条弹幕
第二条弹幕
第三条弹幕
:::
```

每行一条，横向滚动（SMIL `animateTransform`，允许循环）。

### 进度条 `progress`

```
:::progress
70
:::
```

`0`–`100` 的数字，自动收敛到区间。数字后可跟空格加标签：

```
:::progress
70 已完成
:::
```

适合「完成度/进度」可视化。

### 时间线 `timeline`

```
:::timeline
2024 · 事件一
2025 · 事件二
2026 · 事件三
:::
```

每行一个节点，建议「时间 · 事件」格式。

### 对比卡 `compare`

```
:::compare
左：方案 A 的要点
---
右：方案 B 的要点
:::
```

左右对比，内部用 `<table>` 分栏（**不用** `display:grid`，微信会剥）。

## 原始 HTML / SVG 区块 `raw`

`raw` 是专业管线的自由创作区，可用于原创版式、用户素材分层与同等素材复刻：

```
:::raw
<section style="...">...</section>
:::
```

它可以与 Markdown 和其他组件交替出现，原样保留安全 HTML/SVG，适合独特主视觉、异形对白、固定比例画面和多层交互。脚本、事件属性、外部资源标签、表单与可执行协议会被拒绝。含 SVG 的成品可导出为自包含 HTML；复制到目标编辑器时，结构以其粘贴处理为准。

## 校验

渲染时自动检查规格、组件必填内容和 raw 安全边界。需要定位成品结构时，可额外使用 `fishpai_lint`：

- 检查 `id`/`class`/`display:grid`/CSS 变量等微信结构约束；
- 标出 CSS 动画（`animation:`/`transition:`/`@keyframes`），交互动效使用 SMIL；
- 标出 SMIL 在 `height`/`width` 上的 `repeatCount="indefinite"`，`transform`/`opacity` 循环保留。

lint 是提示工具，不是每篇稿子的额外流程，也不阻断交付。

## 预览与复制产物的差别

- **预览**（面板实时预览、`mode:'preview'`）：不做文本包裹，贴近你写的 Markdown。
- **复制/导出**（`mode:'publish'`、「复制到剪贴板」）：自动把文本容器的裸文本包进 `<span>`（对齐微信结构校验），SVG 整块跳过不包。

预览用于编辑过程中的版式确认，复制与导出使用同一篇文稿生成的复制产物。
